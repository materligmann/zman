Privacy

zman asks nothing of you and keeps nothing about you. This page covers the website, the API and the iPhone and Android apps.

What does not exist

No account, no sign-up, no advertising, no analytics, no trackers, no third-party SDKs. The apps request no permissions: no location, no contacts, no notifications.

What travels

To stay in step with the Earth’s rotation, the website and the apps regularly query https://zman.technology/api/now. Like any request on the Internet, it carries the device’s IP address. The server uses it only to rate-limit per address; it does not store it in any database. The host (Google Cloud Run, europe-west1 region) keeps technical request logs under its standard retention policy, which zman does not use.

The request carries no identifier: no account, no advertising identifier, no device identifier.

What stays on the device

The apps keep the last measured correction on the device (an offset in rega’im and the age of the IERS data), so they keep working offline and the widget can use it. None of it leaves the device. On the website, a lang cookie remembers the chosen language, and nothing else.
